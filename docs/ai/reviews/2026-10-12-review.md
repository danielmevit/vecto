## Where Vecto stands
- **v0.4.2** live on the Microsoft Store ($7.99, 9PM61P4NC8J2) and free on GitHub Releases.
  `dev` == `main` @ fd07b8d; last work 2026-07-26.
- **Build broken since 2026-10-07:** five SixLabors.ImageSharp 3.1.12 advisories became
  NU1902/NU1903 errors (TreatWarningsAsErrors). Vecto.Core and Vecto.App build clean, but
  Vecto.Cli and Vecto.Tests fail — and `packaging/windows/build.ps1` publishes the CLI before the
  MSIX, so **Store updates cannot be built** either. No advisory is reachable from Vecto's code
  except the TIFF decoder path (the CLI decodes every format today). Only 4.1.2+ is patched.
- With audit disabled the engine is healthy: 15/15 tests, CLI samples planarity PASS, 12 MP in 4 s,
  `Vecto.exe --smoke` exit 0.
- **New engine bug:** small-region absorption treats the image edge as transparency, eating holes
  into the borders of opaque images (scans/JPEGs/photos); `--check` cannot see it. 1-px diagonal
  lines vanish (relevant to issue #1).
- No CI build/test workflow exists — the break went unnoticed.
- ImageSharp 4.x is not "paid": Six Labors issues a free Community license key to open-source
  projects (yearly renewal; Release builds validate it). GOTCHAS/DECISIONS say otherwise.
- Open issue #1 (2026-10-09): CAD/scanned engineering drawings. "Rate on the Store" prompt not built.

## Findings
1 BLOCKER: audit break blocks release packaging — build.ps1:63 publishes Vecto.Cli (same restore audit) before MSIX (line ~105+), under ErrorActionPreference=Stop. Next Store update can't be built.
2 HIGH->low real risk: none of the 5 advisories reachable from Vecto code paths except TIFF decoder exposure today. All ranges <=4.1.1 (3.2.0 also affected). T4/T6 = TIFF encoders (CLI encodes PNG only); HistogramEqualization unused; ICC CLUT reachable on 3.x only via IccProfile.Entries (unused); BigTIFF needs TIFF decoder — currently `vecto trace t.tif`/`w.webp` work though README promises PNG/JPG/BMP/GIF.
3 MED (docs): ImageSharp 4.x licensing half-wrong in GOTCHAS/DECISIONS. 4.1.3 nupkg build/SixLabors.ImageSharp.targets runs ValidateLicenseTask BeforeTargets=CoreCompile (Release required). licensing.sixlabors.com issues FREE Community key automatically for open-source; scoped to AssemblyName (`vecto`), may be committed publicly, Paddle registration, yearly renewal (Release builds fail when expired). GOTCHAS fallback System.Drawing.Common is wrong (Linux/macOS CLI binaries). Tests needing key: UNVERIFIED.
4 HIGH: border erosion in Segmenter.AbsorbSmallRegions (Vecto.Core/Segmentation.cs:85-92): out-of-bounds neighbour tallied -1 (transparent), wins ties (inserted first). Repro 50x50 opaque white + 1-px red at (0,0) -> transparent notch `M 50 0 L 2.32 0.32 L 0.32 2.32 L 0 50`. Opaque 200x200 noise --style photo loses 2,136 px (5.3%) to transparency up to 9 px in; cascades. Hits scans/JPEGs/photos (issue #1 inputs).
5 MED: `--check` blind to deleted pixels — Vecto.Cli/Program.cs:273-282 compares against post-absorption palette counts; should use input alpha>=128.
6 HIGH (issue #1): 1-px diagonals vanish (4-connectivity splits into 1-2 px runs -> absorbed); 1-px horizontal -> two-curve lens; 2-px vertical -> pointed caps; 1x1 image degenerate (check FAIL 100%); 1x5 lens (25%). Explains "crooked lines/distorted text" independent of binarization.
7 MED: floating Version="3.1.*", no global.json, no CI — break arrived via advisory, undetected 5 days.
8 LOW: vulnerable transitive pkgs in Tests only (xunit 2.5.3 -> NETStandard.Library 1.6.1 -> System.Net.Http 4.3.0, System.Text.RegularExpressions 4.3.0 high); would fail if NuGetAuditMode=all.
9 LOW-MED: App export/copy/paste handlers lack local error handling (MainWindow.xaml.cs:118-149, :77-86) -> generic error dialog + crash log (App.xaml.cs:232), no crash.
10 LOW: App loads images on UI thread, no size cap (MainViewModel.cs:178-198); unchecked w*h*4 overflow >~536 MP (ImageInterop.cs:12, ImageIo.cs:12); failed ToRaster leaves new filename with old result.
11 LOW: AppSettings.Load trusts JSON; negative WindowWidth throws in ctor (MainWindow.xaml.cs:22); enum casts unchecked. Portable mode correct.
12 LOW: AppxManifest.xml:19 says "Free, offline, open source" for paid Store pkg; build.ps1:156 default PFX password in public script (PFX gitignored); console "px²" -> "px?".
Fine: culture invariance, determinism, fully transparent image, palette/gray16/CMYK/animated GIF, cancellation token, fitter degenerate guards.
